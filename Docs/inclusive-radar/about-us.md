## ℹ️ Sobre Nós (AboutUs)

> Página pública institucional do Radar Inclusivo, apresentando o objetivo do projeto, funcionalidades disponíveis, créditos acadêmicos e acesso ao sistema/repositório.

---

### 📋 Requisitos Funcionais (RF)

#### **1. Acesso e Navegação**

| Código | Descrição Detalhada |
| --- | --- |
| `RF-SOB-01` | **Página Pública:** Permitir acesso à página "Sobre Nós" sem exigir autenticação do usuário. |
| `RF-SOB-02` | **Rota Dedicada:** Disponibilizar a página pela rota `/sobre-nos`, identificada pelo nome `sobre-nos`. |
| `RF-SOB-03` | **Navegação Interna:** Exibir links âncora para as seções Home, Sobre, Funcionalidades e Créditos. |
| `RF-SOB-04` | **Acesso ao Sistema:** Disponibilizar chamada para acesso ao painel do sistema pela interface da página. |

#### **2. Apresentação Institucional**

| Código | Descrição Detalhada |
| --- | --- |
| `RF-SOB-05` | **Identidade do Projeto:** Apresentar o nome Radar Inclusivo como elemento principal da página. |
| `RF-SOB-06` | **Objetivo:** Informar que o sistema apoia o mapeamento, registro e acompanhamento de condições de acessibilidade no ambiente institucional. |
| `RF-SOB-07` | **Contexto Acadêmico:** Identificar o projeto como Trabalho de Conclusão de Curso do Instituto Federal Baiano - Campus Guanambi. |
| `RF-SOB-08` | **Resumo Operacional:** Descrever a centralização de dados de alunos, equipe, tecnologias assistivas, materiais acessíveis, barreiras, empréstimos, fila de espera, agenda e relatórios. |
| `RF-SOB-09` | **Indicadores Visuais:** Exibir cartões de destaque com quantidade de funcionalidades, responsividade, natureza acadêmica e ano de desenvolvimento. |

#### **3. Funcionalidades do Sistema**

| Código | Descrição Detalhada |
| --- | --- |
| `RF-SOB-10` | **Catálogo de Módulos:** Listar as principais funcionalidades do Radar Inclusivo em cards com ícone, título e descrição curta. |
| `RF-SOB-11` | **Cobertura Funcional:** Incluir módulos administrativos, operacionais e de apoio, como Dashboard, Relatórios, Notificações, Backups, Cadastros, Barreiras, Empréstimos, Fila de Espera e Agenda Institucional. |
| `RF-SOB-12` | **Descrição Sintética:** Cada funcionalidade deve comunicar sua finalidade em linguagem simples para visitantes externos ao sistema. |

#### **4. Créditos e Referências**

| Código | Descrição Detalhada |
| --- | --- |
| `RF-SOB-13` | **Créditos do Projeto:** Exibir responsável pelo desenvolvimento e orientador/coordenação do trabalho. |
| `RF-SOB-14` | **Contato:** Disponibilizar e-mail de contato dos responsáveis apresentados na seção de créditos. |
| `RF-SOB-15` | **Instituição:** Informar instituição, curso, tipo de projeto e ano de desenvolvimento. |

#### **5. Experiência Visual**

| Código | Descrição Detalhada |

| `RF-SOB-18` | **Layout Responsivo:** Adaptar seções, grids e cards para desktop, tablet e celular. |

### ⚙️ Requisitos Não Funcionais (RNF)

| Código | Categoria | Descrição |
| --- | --- | --- |
| `RNF-SOB-01` | **Acessibilidade** | A página deve usar estrutura semântica, textos alternativos em imagens, ícones com `aria-hidden` quando decorativos e rótulos acessíveis em links principais. |
| `RNF-SOB-02` | **Responsividade** | O layout deve reorganizar menus, grids e cartões em telas menores sem sobreposição de textos ou perda de conteúdo. |
| `RNF-SOB-03` | **Usabilidade** | O conteúdo deve ser direto, com navegação por âncoras e chamadas claras para acessar o sistema e o repositório. |
| `RNF-SOB-04` | **Identidade Visual** | A página deve manter paleta, tipografia e linguagem visual coerentes com a marca Radar Inclusivo. |
| `RNF-SOB-05` | **Performance** | Recursos externos, como fontes, ícones e imagens dos créditos, devem ser carregados de forma compatível com navegação pública. |
| `RNF-SOB-06` | **Manutenibilidade** | Textos institucionais, links e dados de créditos devem permanecer centralizados na view para facilitar atualização durante a evolução do projeto acadêmico. |
| `RNF-SOB-07` | **Compatibilidade** | A página deve funcionar em navegadores modernos com suporte a CSS Grid, Flexbox e JavaScript básico para destaque de seção. |
